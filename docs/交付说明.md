## 三、数据说明（重要，避免误解）

| 项 | 说明 |
|---|---|
| 行情 / 公告 / 热榜 / 龙虎榜 | **扶摇金融数据 API + iFinD MCP 的真实返回**，不是构造数据 |
| 三笔交易 | 价格、日期、热榜排名均为真实；**用户画像与仓位为构造数据**（题目要求匿名或构造） |
| 线上环境 | 未配置数据源凭证，运行在**数据快照模式**：展示录制的真实历史数据，页面顶部有明确横幅 |
| 本地环境 | 配好 `.env.local` 后即为实时取数，无横幅 |
| 写入 | 线上容器的写入是临时的，容器重启后回到种子状态；本地单机不受影响 |

## 四、这个产品最想解决的三件事

1. **后见之明**：日 K 收盘价按 15:00 才可见，所以 10:23 的决策看不到当天收盘价。
   机制上把事后信息从数据流里排除，出口还有一道护栏会直接抛错。
2. **归因不是讲故事**：收益拆成市场 β / 行业超额 / 执行偏差 / 残差，
   拆不开的部分就单列为残差，**不包装成「个股选择能力」**。
3. **学习要能复用**：复盘产出的清单，在建仓前一页调出来，全部确认才能记录决策；
   事后回检价格事实与「你到底有没有照做」。

## 五、已知边界（主动声明）

- 无分钟级行情：盘中决策时点的盘面是空白，界面显式说明，不假装有数据
- iFinD 资讯只到日期粒度：同日判为「时点不确定」，不计入归因权重
- 个股异动解读接口只支持当日查询，无法回溯，未接入
- 假设台账的 `evidence_backed` 档由用户自述「保留了当时的依据」，产品无法验证
- 回检中的执行情况是自述；价格与阈值触及由系统计算
- 仅支持 A 股
