# 合规文案审查

> 依据题目统一规则：不得输出确定性涨跌预测、收益承诺或直接买卖建议；
> 事实、推断与不确定信息必须区分；核心结论必须能回到原始字段或原文。

## 一、审查方法

1. **词表扫描**：对 `src/app/**` 与 `src/components/**` 的 `.tsx` 文件扫描
   `建议|推荐|看好|目标价|上涨空间|必涨|稳赚|应该买|应该卖|值得买|抄底|止盈|预计涨|收益率`。
2. **人工逐页通读**：首页、导入、台账、复盘、模式面板、建仓前检查六个页面。
3. **反向验证**：检查每个结论性数字是否挂着 `sourceEvidenceIds` 或可点开的「溯源」。

扫描命令与结果记录在本文末尾，可复现。

## 二、逐页文案与判定

| 页面 | 关键文案 | 判定 |
|---|---|---|
| `/` 首页 | 「拆开收益里哪部分来自市场、哪部分来自你的判断」 | 描述产品能力，不含预测或建议 ✓ |
| `/` 首页 | 「价格涨跌（未含费用）」/「区间收益（含费用）」 | 两个口径分别标注，不混用 ✓ |
| `/import` | 「数字错一位，后面的归因全错」+ 字段映射回显 + 逐行错误 | 提示数据风险，不涉及投资判断 ✓ |
| `/hypothesis/[id]` | 「什么情况下你承认自己错了（必填）」 | 引导用户写出可证伪条件，不代用户判断 ✓ |
| `/hypothesis/[id]` | 「不要写"看好""有空间"」 | 要求表述精确，属方法论引导，非行情观点 ✓ |
| `/review/[id]` | 「决策时点的盘面是空白，这是数据边界」 | 显式不确定信息，不掩盖缺失 ✓ |
| `/review/[id]` | 「β 不可计算：样本不足，无法估计」 | 缺失即说缺失，不显示 0.00% 冒充「无影响」✓ |
| `/review/[id]` | 「残差：未被以上各项解释的部分（含未知事件与噪声）」 | 明确区分「已解释」与「未解释」，不把残差包装成洞见 ✓ |
| `/review/[id]` | 偏差卡：「卖出后价格继续上行超 10%」+ 判定规则原文 | **只陈述可验证的事实**；「只按感觉决定」属推断，已移出标签并改为中性说明「是否卖错取决于你当时的卖出理由，而台账里没有记录它」✓ |
| `/review/[id]` | 「本页只呈现事实与你自己写下的规则，不预测涨跌、不给出买卖建议」 | 显式免责 ✓ |
| `/patterns` | 「处置效应：命中 … 判定条件 (盈/亏持有比 < 0.5)」 | 统计陈述 + 判定条件公开，样本不足时只报「样本不足」✓ |
| `/patterns` | 「持有期一律按交易日计，收益按含双边费用口径」 | 口径声明 ✓ |
| `/plan` | 「这个页面不判断该不该买，也不给出仓位建议」 | 显式免责 ✓ |
| `/plan` | 清单项：「下单前写下一条证伪条件…」 | 是用户自己历史结论的回放，不是产品给的建议 ✓ |

## 三、三态分离的实现

| 态 | 在产品里的表现 | 代码/数据依据 |
|---|---|---|
| **事实** | 行情、公告、热榜排名、成交价，全部带来源接口与 `raw` 原文 | `Evidence.source` + 「溯源」展开 |
| **推断** | 偏差命中、归因分解，每条挂 `rule` 与 `evidenceIds` | `BiasHit.rule` / `Attribution.inputs.sourceEvidenceIds` |
| **不确定** | 时点不确定的证据单独成区；缺口与降级在结论旁标注；样本不足不下结论 | `VisibilityVerdict='uncertain'` / `gaps` / `lowSample` |

关键约束：**推断不写进事实区**。归因面板与偏差卡是独立区块，不混在时间线里；
时间线只放证据，且每条证据都能展开看到判定理由。


三处命中均为**否定式表述或方法论引导**，无一处构成行情观点：

- 前两条是免责声明（「不给出…建议」）；
- 第三条是要求用户把模糊的看多措辞替换成可检验的判断，恰好是反「口号式看好」的设计。

## 五、建议句式的统一改写

产品里不允许出现「你当时应该止损 / 应该加仓」这类句式。统一改写为：

> 你写下的证伪条件是 **X**，它在 **T+n** 触发，若按此执行结果会是 **Y**。

实现位置：偏差卡片的 `evidenceText` 只陈述「你的规则是什么、发生了什么、差多少」，
判断交给用户。例：

```
卖出缺少规则，只按盈亏感觉决定
卖出后 10 个交易日内最高收盘 444.00，较卖出价再涨 15.2%
判定规则：卖出后 10 个交易日内最高收盘 / 卖出价 − 1 > 10%
```

只给事实与规则，不给「下次应该怎样」。
